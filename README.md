# Flowboard — умный канбан-менеджер

Одностраничный русскоязычный Kanban-интерфейс на HTML/CSS/JavaScript и API на Node.js + Express.

## Запуск

Требуется Node.js 18 или новее.

\`\`\`bash
npm install
npm start
\`\`\`

Откройте `http://localhost:3000`. Проверка доступности API: `GET /api/health`.

## ИИ-подзадачи

- Если задан `OPENAI_API_KEY`, сервер использует OpenAI Chat Completions API. Модель по умолчанию — `gpt-4o-mini`.
- Необязательно задать `OPENAI_MODEL`, чтобы выбрать другую доступную модель.
- Если ключ не задан или API временно недоступен, приложение использует четыре резервные подзадачи-шаблона. Интерфейс сообщает, когда сработал резервный режим.

Передавайте ключ через переменные окружения сервера. Не помещайте секретный ключ в `index.html` и не коммитьте его в репозиторий.

## API

| Метод | Маршрут | Назначение |
|---|---|---|
| GET | `/api/health` | Проверка сервера |
| GET | `/api/tasks` | Список задач |
| POST | `/api/tasks` | Создание задачи |
| PUT | `/api/tasks/:id` | Изменение названия, описания или колонки |
| POST | `/api/tasks/:id/suggest-subtasks` | Генерация четырёх подзадач |
| PATCH | `/api/tasks/:id/subtasks/:subtaskId` | Отметка подзадачи выполненной/невыполненной |

Допустимые значения колонки: `backlog`, `in-progress`, `done`.

## Проверки

```bash
npm test
```

GitHub Actions запускает тесты API и проверку отдачи HTML при push в `main` и при pull request.

## Ограничения текущей версии

Задачи хранятся в памяти процесса: при перезапуске сервера они сбрасываются. Для постоянного хранения нужна база данных. Резервный режим генерации без `OPENAI_API_KEY` — это шаблоны, а не генерация настоящей языковой моделью.
